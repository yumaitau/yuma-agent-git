## Pipeline

A fresh Cloudflare container receives the native source from D1/R2 and executes:

```sh
npm ci --no-audit --no-fund
npm run lint
npm run typecheck -w worker && npm run typecheck -w yag
npm test -w worker -- test/dashboard-api.test.ts test/collaboration.test.ts test/auth.test.ts --maxWorkers=1 --silent --testTimeout=120000
npm run test:ui -w worker -- --maxWorkers=1 && YAG_GIT_SMOKE=1 npm test -w yag
npm run build -w worker && npm run build -w yag
CLOUDFLARE_SEND_METRICS=false npx wrangler deploy --dry-run -c worker/wrangler.jsonc --outdir /tmp/yag-worker-build
docker build --quiet --network=host -t yag-self-runner -f worker/runner/Dockerfile worker/runner
```

The pipeline has a ten-minute limit, required checks, protected default branch,
and zero required human approvals for this solo pilot. It validates the application
and runner build; automatic deployment and image publication are not configured.
Build outputs live inside the ephemeral VM. Logs are checkpointed at stage boundaries
and on completion, then retained for seven days.
